Expense Tracker

Project Description

The Expense Tracker is a web application developed to help users manage and monitor their daily expenses. It allows users to add, view, and track their income and spending in an organized way. The main objective of this project is to provide a simple interface where users can keep track of their financial activities and understand their spending habits.

Features

Add new expenses and income

Display a list of all transactions

Track total balance, income, and expenses

Simple and user-friendly interface

Organized transaction history


Technologies Used

React.js

JavaScript (ES6)

HTML5

CSS3
